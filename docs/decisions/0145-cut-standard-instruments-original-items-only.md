# ADR 0145: Cut: DCS, DRS, GCOS-24, MMIC and NVS; eight original patient items and a SILS stratifier

- **Status:** Accepted
- **Date:** 2026-11-20
- **Deciders:** lane C (journey and explain), for the controller

## Context
Research 04 section 2.1: the hackathon Terms bar third-party-protected content; DCS and DRS are free only if not altered and not used for profit; GCOS-24, MMIC and NVS have no usable licence text; no Arabic or Urdu versions were found.

## Decision
`closure.yaml` holds eight original items, scored item by item only where there is a key (items 3 and 4) or an engine number (item 2, within an illustrative tolerance). There is no total score. The Single Item Literacy Screener (CC BY, Morris 2006) is an optional stratifier with attribution and an unvalidated draft translation.

## Consequences
We cannot claim a validated measure. The pilot path is to request written terms for DCS, DRS and GCOS-24.

## Revisit trigger
Written permission including translation and commercial use, and a forward-and-back Arabic and Urdu translation.
